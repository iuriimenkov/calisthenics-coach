# AI-тренер по калистенике

Веб-приложение: через камеру телефона распознаёт элемент калистеники, считает повторы и время удержания, оценивает качество выполнения в процентах и подсказывает голосом. Видео обрабатывается на устройстве (MediaPipe Pose).

- `index.html` — интерфейс
- `logic.js` — распознавание, подсчёт, оценка качества
- `test/test.mjs` — проверка логики: `node test/test.mjs`
